# 前端联调交接说明

> 当前结构：MySQL 位于虚拟机，Windows Flask 对外提供查询 API；完整部署说明见 `项目业务架构与代码规划.md`。

> 目标：让前端同学只通过 Flask API 调试大屏，不直接操作 MySQL。

前端验收环境固定为 Node.js 23 及以上、Vue 3 和 DataV。至少展示两组维度对比，建议使用“工作日 vs 周末”和“不同平台”，并组合 KPI、环图、柱图、折线/面积图、雷达图、热力图和排行条形图，避免全部使用同一种图表。

## 1. 连接边界

前端只调用 `analytics-query-api`，不直连 MySQL。当前后端因实训约束使用恢复模式 root 连接，该连接只保存在 Git 忽略的 `.local/ncs.env`，不写入前端代码。

管理 API 和数据库窗口始终默认绑定 `127.0.0.1`，不作为前端接口开放。

## 2. 本地配置

复制 `config/handoff.example` 为 `.local/ncs.env`，再填写本机值：

```text
NCS_DATABASE_URL=mysql+pymysql://root@<vm-ip>:3306/ncs_analytics
NCS_MYSQL_SECURITY_MODE=recovery_root
NCS_QUERY_HOST=127.0.0.1
NCS_QUERY_PORT=5000
NCS_QUERY_API_KEY=<random-development-api-key>
NCS_CORS_ORIGINS=http://localhost:5173
```

`.local/` 已被 Git 忽略。启动脚本自动读取 `.local/ncs.env`，但现有进程环境变量优先，不会被本地文件覆盖。

如果后端和前端不在同一台电脑，后端可以临时设置 `NCS_QUERY_HOST=0.0.0.0`，并将前端实际 Origin 加入 `NCS_CORS_ORIGINS`。此时还应使用系统防火墙限制 5000 端口只允许可信局域网设备访问。

## 3. 前端请求

配置 API Key 后，前端所有 `/api/v1/*` 请求任选一种方式携带：

```http
X-API-Key: <random-development-api-key>
```

或：

```http
Authorization: Bearer <random-development-api-key>
```

未配置 `NCS_QUERY_API_KEY` 时保持本地开发兼容，不要求认证。存在浏览器 `Origin` 时必须位于 `NCS_CORS_ORIGINS` 中；无 Origin 的本机脚本请求不受 CORS 限制。

## 4. 启动与检查

如果需要从最新 ADS v2.3 交接包重新装载本地验证库，先执行：

```powershell
python scripts/import_ads_v23.py --package <extracted-contract-package> --sqlite .local/ncs-v23.sqlite
$env:NCS_DATABASE_URL = "sqlite:///D:/SHIJIAN/SPARK/ncs-result-backend/.local/ncs-v23.sqlite"
```

虚拟机 MySQL 联调时，先确认 `skip_grant_tables=ON`，再使用无密码 root 连接串。前端仍只访问 HTTP API。

Windows 远程模式的完整顺序如下：

```powershell
# 1. 恢复模式 root 初始化虚拟机 MySQL（只需在结构变化时执行）
python scripts/setup_mysql_ads.py --initialize --url $env:NCS_DATABASE_URL

# 2. 导入 ADS v2.5（数据库结构已初始化，因此跳过 DDL）
python scripts/import_ads_v23.py --package <extracted-contract-package> --database-url $env:NCS_DATABASE_URL --skip-initialize

# 3. 启动查询后端
python scripts/run_query.py
```

```powershell
python scripts/run_query.py
```

前端先检查：

```text
GET /health/live
GET /health/ready
GET /api/v1/meta/capabilities
GET /api/v1/dashboard/manifest
```

也可以使用仓库内的自动检查：

```powershell
python scripts/verify_query_api.py --base-url http://127.0.0.1:5000
```

检查通过后，前端项目保持其默认代理地址 `http://127.0.0.1:5000`，并关闭 `VITE_USE_MOCK`、`VITE_DEMO_DATA`，即可进入真实数据 UI 联调。前端源码不需要复制或修改本仓库。

`health` 接口不要求 API Key，业务接口要求。

## 5. 安全打包

确保工作区已经提交并且没有未提交改动，然后运行：

```powershell
python scripts/package_frontend_handoff.py
```

脚本使用当前 Git `HEAD` 创建 `dist/ncs-frontend-handoff.zip`，因此不会包含 `.local/`、`.env`、缓存、本地数据库和未跟踪文件；生成后还会再次检查常见密钥和数据库文件类型。

不要直接压缩整个工作目录。直接压缩可能把被 Git 忽略的本地配置、数据库文件和缓存一起发送出去。
