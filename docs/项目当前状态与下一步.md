# 项目当前状态与下一步

> 状态日期：2026-09-14  
> 当前分支：`feature/db-console`  
> 本文是项目进度、业务边界和近期任务的唯一当前入口；历史规划与本文冲突时，以本文和 `当前范围决策.md` 为准。

## 1. 当前结论

项目已经完成 ADS v2.1 模拟联调包到 MySQL 结果库和大屏查询 API 的首轮端到端闭环，可以进入前后端联合调试。当前不是“只有骨架”，也不是“等待 MySQL 环境”；尚未完成的是管理入口整合、正式 ADS v2.2 适配和部署加固。

当前业务边界固定为：接收上游已经处理完成的数据，负责结果库存储、校验、发布、回滚、管理后端和大屏查询后端。ODS/DWD/DWS/ADS 加工以及机器学习训练、推理、特征工程和模型管理不属于本仓库。

## 2. 已完成

- 工程骨架、公共响应、错误码、Manifest、Schema、质量规则和批次状态机。
- SQLite 本地开发库、版本化迁移、staging、发布和显式回滚。
- 简易数据库窗口：状态、日志、SQL 执行以及可选 Windows 服务启停。
- ADS v2.1 包文件集合、字段数、行数、SHA-256 和跨文件对账校验。
- A0/Wave B 共 9 个逻辑数据集的显式转换、结果表、索引、发布视图和幂等导入。
- MySQL 8.0.46 真实迁移、首次/重复导入、事务失败回滚和执行计划检查。
- `ncs_ads_migrator`、`ncs_ads_admin`、`ncs_ads_reader` 三账号权限隔离；查询账号只能读取 9 个 `api_v1_*` 必需视图。
- 前端元数据、总览、平台、时长、工作日/周末、热力图、排行、趋势和过程摘要接口。
- ADS v2.1 同步管理导入接口：支持服务器本地解压包和 `A0`/`B` 波次选择，复用现有校验与导入逻辑。
- MySQL 统一运维入口：支持幂等迁移、固定视图授权和迁移/管理/查询三账号权限自检。
- 模型预测视图被定义为可选上游能力；缺失时不影响当前结果库健康状态。

## 3. 当前可用链路

```text
ADS v2.1 交接包
  -> 包完整性与对账校验
  -> A0 / Wave B 显式转换
  -> MySQL rpt_* 结果表
  -> ctl_* 批次、质量与发布记录
  -> api_v1_* 只读视图
  -> Flask 查询 API
  -> Vue / ECharts 大屏
```
