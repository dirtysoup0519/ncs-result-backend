# 机器学习数据集导出与使用说明

## 1. 用途

本说明用于将 `ncs_analytics` 结果库中的已发布数据导出为 CSV 数据集，并交给机器学习同学训练和验证模型。训练仍由模型同学负责；本仓库只负责导出、校验外部模型并执行推理。

导出工具只读取当前 `PUBLISHED` 批次，不导出控制表、历史失效批次或未发布数据。数据库中的时间字段来自上游脱敏数据，只能当作连续业务时间使用，不能解释为真实运营日期。

## 2. 已生成的交接包

导出目录默认位于仓库根目录的 `data_exchange/exports/`（该目录被 Git 忽略）。历史交接包路径仅作留档，不作为新机器的固定路径。

```text
data_exchange/exports/ml-dataset-<batch-id>.zip
```

解压后包含：

| 文件 | 行数 | 建议用途 |
|---|---:|---|
| `load_hourly.csv` | 16,872 | 小时负荷预测主数据集 |
| `station_hour_daily.csv` | 4,840 | 站点与小时维度特征 |
| `fee_energy_daily.csv` | 341 | 日订单、电量、费用趋势特征 |
| `process_daily.csv` | 299 | 日充电过程特征 |
| `dataset_manifest.json` | - | 字段、行数、用途和 SHA-256 校验信息 |

## 3. 机器学习同学如何使用

优先使用 `load_hourly.csv`。该文件按小时升序排列，从 `2014-01-24 18:00:00` 到 `2015-12-28 17:00:00`，连续性检查没有发现断点。

主要字段：

| 字段 | 含义 | 使用建议 |
|---|---|---|
| `stat_time` | 脱敏后的连续业务时间 | 解析为时间类型，可派生小时、星期、月份等特征 |
| `total_kwh` | 小时充电量 | 可作为回归预测目标 |
| `order_count` | 小时订单数 | 可作为另一种预测目标或输入特征 |
| `is_observed` | 是否为上游观测值 | `1` 为观测值，`0` 为补齐值 |
| `fill_method` | 缺失小时的补齐方式 | 训练前检查不同补齐方式的影响 |
| `time_quality` | 时间质量标记 | 可用于过滤低质量样本 |
| `allocation_method` | 小时电量分配方法 | 建议作为类别特征或质量分析字段 |
| `data_version` | 数据版本 | 用于复现实验，不建议作为模型特征 |

Python 读取示例：

```python
import pandas as pd

df = pd.read_csv("load_hourly.csv", encoding="utf-8-sig")
df["stat_time"] = pd.to_datetime(df["stat_time"])
df = df.sort_values("stat_time").reset_index(drop=True)

assert not df["stat_time"].duplicated().any()
assert df["stat_time"].diff().dropna().eq(pd.Timedelta(hours=1)).all()

observed_df = df[df["is_observed"] == 1].copy()
X = observed_df[["stat_time", "order_count"]]
y = observed_df["total_kwh"]
```

注意：时间序列必须按时间切分训练集、验证集和测试集，不能随机打乱后切分，否则会产生未来数据泄漏。

## 5. 导出结果验收

每次交付前至少检查：

1. 脚本输出的 `rowCount` 大于 0。
2. ZIP 中存在 CSV 和 `dataset_manifest.json`。
3. `load_hourly.stat_time` 无重复，且相邻记录间隔均为一小时。
4. `dataset_manifest.json` 中的 `sha256` 与收到的 CSV 一致。
5. 训练时记录数据文件的 `sha256` 和 `data_version`，保证模型实验可以复现。

PowerShell 计算文件校验值：

```powershell
Get-FileHash "D:\SHIJIAN\SPARK\ml-dataset\load_hourly.csv" -Algorithm SHA256
```

## 6. 常见问题

### 提示缺少数据库地址

如果出现：

```text
--database-url or NCS_DATABASE_URL is required
```

需要先设置 `NCS_DATABASE_URL`，或者在命令中显式传入 `--database-url`。

### 出现 `Access denied`

当前实训环境应使用恢复模式无密码 root。确认 MySQL 的 `skip_grant_tables=ON`，连接串中没有密码，并确认 Windows 能访问虚拟机 3306 端口。

### 导出的 CSV 为空

先确认 ADS v2.3 数据已经导入，而且对应数据集在 `ctl_publication` 中处于 `PUBLISHED` 状态。导出工具不会读取未发布批次。

### Excel 打开中文乱码

CSV 使用 `UTF-8 with BOM` 编码。若软件仍乱码，应在导入功能中手动选择 UTF-8，不要直接修改原始 CSV 编码。

## 7. 数据边界

- 本项目只负责管理上游处理后的结果数据并提供后端服务，不负责训练、评估或部署机器学习模型。
- `load_hourly` 是连续化后的统计数据，不是原始充电枪遥测数据。
- `is_observed=0` 的数据是否参与训练，由机器学习同学根据模型方案决定，但必须保留该标记。
- 模型产物及预测结果如需回传，应另行冻结输入字段、输出字段、模型版本和预测时间范围合同。
