# NCS 待确认问题与风险清单

> 状态：设计审查结果，供接口字段设计和实现排期使用  
> 分支：`design/internal-architecture`  
> 审查范围：`内部逻辑与对接设计.md`、`data-contract.md`、`api-contract.md`  
> 结论：抽象边界和协议结构无阻断性矛盾，但以下输入缺口必须在落地 DDL、视图和接口字段前关闭

> **当前范围覆盖说明（2026-09-14）**：模型目标、特征、训练、评估和制品相关问题已移至未来扩展，不再阻断当前结果库与后端开发。当前只要求上游交付可直接入库的处理后数据及其 Schema、Manifest 和质量说明。详见 `当前范围决策.md`。

## 1. 审查结论

目前设计已经把职责拆成四个边界：

```text
Hive ADS / 特征数据
  -> ml-pipeline（训练、评估、离线预测）
  -> data-admin-service（导入、校验、发布、回滚）
  -> MySQL 结果库及 api_v1_* 视图
  -> analytics-query-api
  -> Vue/ECharts Web 大屏投射
```

已确认的原则：

- Qt、交易业务、设备控制和 Socket 不属于当前范围。
- 前端不直连 MySQL，只通过查询 API 访问只读视图。
- 查询 API 不训练模型、不执行导入、不暴露任意 SQL。
- 模型预测以离线批次发布，不在大屏请求链路中实时推理。
- 统计结果和预测结果分开发布；新批次失败不影响旧数据查询。

| 主题 | 当前保留选择 | 决策时机 |

## 5. 当前已知数据质量风险

来自现有项目资料的风险必须在机器学习和结果库中显式处理：

1. 充电过程 `record_time` 使用科学计数法且可能丢失具体时间精度，不能仅凭经验还原。
2. 订单 `created` 存在 `0014`、`0015` 等异常年份，修复为 2014/2015 前必须确认规则。
3. 订单与充电过程不是一对一完整覆盖，缺少过程记录不能直接当作脏数据。
4. 站点维度关联虽有静态覆盖结论，但仍需在每个 ADS 批次执行质量检查。
5. 课件中的示例数字、字段和预测图不能当作正式数据合同。
6. `交接包(2).zip` 的模拟过程时间戳已逐行唯一并与订单开始时刻对齐，但仍是一会话一条采样，不能视为连续过程数据。
7. 新训练导出中的订单时间为 `0014/0015`、过程时间为 2019；若跨表使用，必须先统一逻辑时间轴。
8. ODS 后续提供的 `nvv2t_md_end(1).csv` 已修复重复表头，含 105 个唯一 `stationId`；但 `facilityType`、`locationId`、`device_count` 和 `update_time` 的业务语义尚未冻结。

处理原则：保留原值或质量标记；阻断训练所需时间字段进入模型；不在 API 层偷偷修正业务数据。

## 6. 下一步关闭顺序

建议按以下顺序推进，避免先写大量不可用代码：

1. 按前端 V1 波次冻结主题：Wave A 为数据状态、总览、订单平台分布、按费用站点排行、费用与电量趋势、过程聚合；Wave B 为时长、画像和热力图；Wave C 为负荷预测。
2. 收集 ADS DDL、样例和批次信息，完成 `data-contract.md` 的真实字段映射。
3. 确认指标公式、时间口径、单位、精度和空值；V1 不实现比较指标。
4. 先做时间质量报告，再冻结预测目标、特征版本、训练窗口和验收阈值。
5. 确认 MySQL、Sqoop、调度器、投屏鉴权和坐标系。
6. 编写第一版结果表、`api_v1_*` 视图和 P0 API 字段级合同。
7. 用一批真实 ADS 数据完成导入、质量校验、发布、查询和投屏联调。
8. 通过真实查询性能和模型回评后，再决定缓存、batch、Webhook 和扩展主题。

## 7. 允许先做与禁止先做

### 可以先做

- 项目目录、服务边界、错误码、通用响应和状态机骨架。
- Manifest、指标目录、Schema 注册和契约测试框架。
- 使用小样例数据验证导入、视图权限、API 映射和投屏降级。
- 为模型登记、预测运行和质量规则预留接口。

### 暂不应做

- 在没有 ADS DDL 的情况下确定最终业务字段和结果表列。
- 根据演示大屏截图人工编造指标或预测值。
- 根据异常时间字段训练模型或生成看似精确的高频预测。
- 让前端直连表、执行 SQL 或选择任意视图。
- 把模型训练放进查询请求线程。
- 因为接口已经列出，就实现用户、订单、设备控制等 Qt/交易功能。

- MySQL 账号、权限和导入方式不依赖个人机器上的临时配置。
