# 文档现行基线

> 更新时间：2026-09-15
> 适用分支：`feature/ads-shell-sync`

本文件解决历史交接包和多轮设计文档之间的版本歧义。新接手人员只按下面的优先级阅读和操作：

1. 根目录 `README.md`：新机器前置条件、安装、启动、数据更新、Shell 同步和模型目录操作。环境或配置变更必须同步更新这里。
2. `docs/项目业务架构与代码规划.md`：当前业务边界、真实架构和实施规划。
3. `docs/项目当前状态与下一步.md`：当前已完成、待确认项和验收基线。
4. `docs/当前范围决策.md`：职责边界，尤其是“外部训练、本项目受控推理”。
5. `docs/ADS_Spark_v3.2完整交接包评审.md`：当前上游交付事实、数据变化和兼容结论。
6. `docs/ADS_v2.5自动同步与模型推理设计.md`：下游 18 数据集合同、虚拟机 Shell 自动同步和模型推理设计；文件名沿用历史版本。
7. `docs/大屏接口冻结合同_v1.md`、`docs/前端接口协议.md`、`docs/api-contract.md`、`docs/data-contract.md`：前后端和数据合同。
8. `docs/双运行位置数据接入设计.md`、`docs/前端联调交接说明.md`：部署位置和联调操作边界。

## 当前不可混用的历史内容

- ADS v2.1、v2.3 和旧 v2.5 包的评审与计划：仅用于追溯字段、指标和决策演进；当前上游包为 v3.2，下游合同仍为 Schema 2.2.0 的 18 个数据集。
- 三账号、授权、最小权限和退出 `skip-grant-tables` 的命令：仅为历史实验；当前隔离 VMware 实训使用 MySQL 5.7.35 恢复模式下的无密码 root 单连接。
- 训练流水线、调参、模型评估和任意模型上传：不属于本项目；当前只加载外部交付模型并执行受控推理。
- ODS/DWD/DWS 脚本和原始数据：不复制到本仓库，不直接执行交接包中的 SQL。

历史文档保留原始证据，但其文件头必须标明“历史留档”或“不可执行”。若历史文档与本文件、README 或当前状态文档冲突，以现行基线为准。
