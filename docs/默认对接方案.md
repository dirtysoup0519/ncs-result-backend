# NCS 默认对接方案

> **当前范围覆盖说明（2026-09-14）**：机器学习对接内容仅作为未来备选。本项目当前不登记模型、不执行训练或推理；预测结果若存在，按普通处理后数据集接收。详见 `当前范围决策.md`。

> 状态：内部推进方案，不代表外部团队已经确认
> 目的：在等待数仓、前端、环境和算法最终材料期间，先完成可替换的合同、校验和程序骨架
> 规则：所有默认值标记为 `ASSUMED`；收到可复核材料后改为 `CONFIRMED`，存在冲突时修改适配器或提升合同版本

## 1. 决策分级

| 状态 | 含义 | 是否允许进入生产 |
| --- | --- | --- |
| `CONFIRMED` | 有 DDL、样例、原型、环境说明或负责人书面确认 | 可以按验收流程进入 |
| `ASSUMED` | 为了内部开发选定的可替换默认值 | 不允许据此宣称联调完成 |
| `BLOCKED` | 缺失信息会导致数据错误、安全问题或模型无效 | 不允许实现依赖该信息的正式逻辑 |

代码和合同样例可以使用 `ASSUMED` 方案，但真实表结构、生产连接、指标口径和模型启用必须基于 `CONFIRMED` 结论。

## 2. 与数仓的默认对接

### 2.1 交付方式

默认采用“数据文件 + Manifest”交付：

- 数据格式：UTF-8 CSV，允许通过适配器增加 TSV、Parquet 或 JDBC。
- 每个数据文件必须有独立 Manifest，声明数据集代码、schema 版本、数据日期、粒度、行数、校验和和生成时间。
- 一个批次可以包含多个数据集，但每个数据集独立校验和发布。
- 文件只写入 staging；质量检查通过后才能进入结果表。
- 正式导入方式确认后，仅替换 `Importer` 适配器，不改变批次、质量和发布服务。

### 2.2 默认字段规则

| 项目 | 默认规则 | 状态 |
| --- | --- | --- |
| 字段名 | `snake_case` | `ASSUMED` |
| 日期 | `YYYY-MM-DD`，业务统计时区为 `Asia/Shanghai` | `ASSUMED` |
| 时间戳 | ISO 8601，传输和系统审计统一 UTC | `ASSUMED` |
| 金额 | 十进制定点值，单位元 | `ASSUMED` |
| 比例 | `[0,1]` | `ASSUMED` |
| 空值 | 空字段表示未知，业务零值必须写 `0` | `ASSUMED` |
| 唯一键 | Manifest 中按完整粒度声明 | `ASSUMED` |
| 校验和 | SHA-256，小写十六进制 | `ASSUMED` |

已知适配规则：上游 `fee_ratio` 如果是 0～100 百分数，在进入 API 合同前转换为 `[0,1]`；小时缺口由查询层补齐并标注 `isObserved=false`；近似修复的时间不得作为精确采样时间。

### 2.3 默认首批数据集

- `ads.kpi_total`
- `ads.revenue_daily`
- `dws.order_hourly`
- `dws.station_daily`
- `dws.process_daily`
- `ml.station_load_features`
- `ml.load_prediction`

这些代码是内部稳定标识，不要求等于 Hive 物理表名。实际表名通过数据集登记和导入适配器映射。

## 3. 与 MySQL/环境的默认对接

内部开发基线为 MySQL 8.0、`utf8mb4`、InnoDB。系统审计时间使用 UTC，业务统计日期按 `Asia/Shanghai` 解释。

账号边界：

- 迁移账号：创建和变更表、视图，仅迁移时使用。
- 管理服务账号：写 staging、控制表和结果表，无任意 DDL 权限。
- 查询服务账号：只能读取 `api_v1_*` 视图。
- 机器学习任务：默认通过管理服务登记结果，不直写发布表。

本地开发允许先使用内存仓储验证领域逻辑；Iteration 3 再接入 SQLAlchemy/MySQL。真实连接信息只能通过安全渠道和环境变量提供。

## 4. 与前端大屏的默认对接

默认使用 HTTP/JSON 和 `/api/v1` 前缀，浏览器不得直连数据库。首批能力：

- 服务能力和数据状态。
- 总览指标。
- 平台分布、充电时长分布和工作日/周末画像。
- 日趋势、24 小时分布和站点小时热力图。
- 站点排行、站点列表和充电过程状态概览。
- 已发布负荷预测。

前端 V1 文档已经确认：平台组件统计订单；站点 Top10 默认按总费用；趋势只展示充电费用和充电量，不含无来源的服务费/利润；V1 不展示“较上期”；过程指标是历史聚合而非实时设备遥测；运营建议先由前端使用本地模板生成。时长桶边界、雷达归一化、活跃站点周期、热力图站点范围、预测目标及区间仍是 `ASSUMED` 或 `BLOCKED`，详见 `前端大屏原型对接分析.md`。

默认行为：

- 响应携带 `dataDate`、数据版本、新鲜度和 `traceId`。
- 空数据返回成功响应和空集合，不伪造零；只有确定的缺失时间槽才补零并标记非观测值。
- 单组件失败不影响其他接口。
- 预测未启用时返回 `CAPABILITY_DISABLED`。
- 预测接口在 `cutoffHour` 之后不得返回或展示未来实际值；回测数据使用独立合同。
- 前端建议的 `/api/v1/dashboard/*` 路径由其 API 封装层映射到本项目领域路由，组件不直接拼接 URL。
- 接口返回业务数据，不返回 ECharts `option`；万元、MWh 等展示单位由前端从 CNY、kWh 基础单位换算。
- 默认只允许可信网络内匿名只读联调；正式部署前必须确认鉴权、跨域、限流和数据范围。

需要前端最终确认：组件与接口映射、筛选项、排序、分页、地图坐标系、最后成功数据保留方式、错误和过期提示。

## 5. 与机器学习的默认对接

为了先完成流水线合同，暂定一个不可直接生产启用的基线问题：

- 粒度：站点 + 小时。
- 默认目标：未来时段充电电量，单位 kWh。
- 预测时域：1h、6h、24h。
- 切分：严格按时间切分，不随机打散。
- 基线：同站点上一周期/同星期时段值。
- 结果必须包含模型版本、特征版本、预测生成时间和目标时间。

以上均为 `ASSUMED`。以下信息仍为 `BLOCKED`，获得确认前不得训练并启用正式模型：

- 最终预测目标和标签定义。
- 可用特征、时间语义和历史范围。
- 时间字段质量及修复标记。
- 基线、MAE/RMSE/MAPE 评估窗口和启用阈值。
- 模型制品存储位置与权限。

## 6. 内部替换点

| 外部变化 | 只允许影响的适配点 | 不应影响 |
| --- | --- | --- |
| CSV 改为 JDBC/Sqoop/Parquet | `Importer` | 批次和发布状态机 |
| Hive 表名改变 | 数据集映射 | API 字段 |
| MySQL 地址或驱动改变 | Repository/配置适配器 | 领域规则 |
| 前端字段展示调整 | DTO 映射/API 版本 | 结果表血缘 |
| 模型框架改变 | `Trainer`/`Predictor` | 模型登记合同 |
| 鉴权方式改变 | HTTP 认证适配器 | 查询用例 |

## 7. 当前推进结论

当前可以独立推进：Manifest、Schema、质量规则、批次/模型/预测状态机、合同样例和单元测试。

进入真实数据库和真实数据集实现前，仍需获得：ADS/DWS DDL 与样例、MySQL 环境、首屏组件合同、预测目标和验收阈值。未获得时使用内存或合同样例测试，并在交付说明中明确标记未完成真实联调。
