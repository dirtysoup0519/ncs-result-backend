# 仓库下载与联调操作手册

> 环境更正：当前虚拟机实测为 MySQL 5.7.35，尚未完成兼容验收。双运行位置和实际门槛见 `项目业务架构与代码规划.md`。

> 适用对象：前端、ADS、后端和项目集成同学  
> 适用环境：Windows、Python 3.11 或 3.12、MySQL 8.0+（虚拟机）
> 安全要求：不得在 Git、截图、群聊或交接压缩包中保存真实密码和 Token

## 1. 先选择调试方式

### 方式 A：前端只连接已经启动的后端

前端不需要安装 MySQL，也不需要任何数据库密码。后端同学只提供：

- 查询 API 地址，例如 `http://<backend-host>:5000`；
- 开发 API Key（后端启用认证时）；
- 允许使用的接口合同。

前端不能访问管理 API、数据库窗口或 MySQL。

### 方式 B：在自己的电脑运行查询后端

需要安装 Python 和 MySQL，并准备已经建好的 `ncs_analytics` 数据库。后端只使用 `ncs_ads_reader` 只读账号。

### 方式 C：进行 ADS 导入和完整联调

除 Python、MySQL 外，还需要：

- ADS v2.1 解压目录；
- 迁移账号；
- 数据管理账号；
- 查询只读账号；
- 仅在首次授予视图权限时使用的特权账号。

## 2. 下载仓库

```powershell
git clone https://github.com/dirtysoup0519/ncs-result-backend.git
cd ncs-result-backend
git switch feature/db-console
```

确认当前代码：

```powershell
git status
git log -1 --oneline
```

`git status` 应显示工作区干净。不要从别人正在开发且存在未提交文件的目录直接复制项目。

## 3. 创建 Python 环境

最终实训和答辩只使用 Python 3.11 或 3.12。不要用上游节点记录中的 Python 3.10 作为验收环境。

本项目的 MySQL 运行在虚拟机内，Windows 上的后端是外部客户端。配置数据库 URL 时使用虚拟机 IP，不能使用 `localhost`。联调前确认 Windows 能访问该 IP 和 3306，MySQL 监听虚拟机业务网卡，并为各项目账号授予来自 Windows 地址的最小权限；禁止远程使用 root。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[mysql,dev]"
```

检查代码基线：

```powershell
python -m pytest -q
```

未配置 MySQL 时，MySQL 环境测试会显示 `skipped`，这是正常现象；普通测试必须全部通过。

## 4. 配置本地环境

创建被 Git 忽略的本地目录并复制模板：

```powershell
New-Item -ItemType Directory -Force .local
Copy-Item config/handoff.example .local/ncs.env
```

然后只在自己电脑上编辑 `.local/ncs.env`：

```text
NCS_DATABASE_URL=mysql+pymysql://ncs_ads_reader:<reader-password>@<vm-ip>:3306/ncs_analytics
NCS_QUERY_HOST=127.0.0.1
NCS_QUERY_PORT=5000
NCS_QUERY_API_KEY=<random-development-api-key>
NCS_CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

规则：

- `NCS_DATABASE_URL` 只能使用查询只读账号运行查询服务。
- 不要把 root、迁移或管理账号填进前端配置。
- `.local/ncs.env` 不提交、不发送。
- 已存在的系统环境变量优先于本地文件。
- 如果密码含 `@`、`:`、`/`、`#`、`%` 等 URL 特殊字符，先进行 URL 编码。

## 5. 启动查询后端

```powershell
python scripts/run_query.py
```

默认地址：`http://127.0.0.1:5000`。

另开一个 PowerShell 窗口检查：

```powershell
Invoke-RestMethod http://127.0.0.1:5000/health/live
Invoke-RestMethod http://127.0.0.1:5000/health/ready
```

配置了 API Key 后，调用业务接口：

```powershell
$headers = @{ "X-API-Key" = "<random-development-api-key>" }
Invoke-RestMethod http://127.0.0.1:5000/api/v1/meta/capabilities -Headers $headers
Invoke-RestMethod http://127.0.0.1:5000/api/v1/dashboard/manifest -Headers $headers
```

## 6. 前端连接方式

前端请求基地址：

```text
http://127.0.0.1:5000
```

Axios 示例：

```javascript
import axios from "axios";

export const api = axios.create({
  baseURL: import.meta.env.VITE_NCS_API_BASE_URL,
  headers: {
    "X-API-Key": import.meta.env.VITE_NCS_API_KEY,
  },
});
```

前端自己的本地配置示例：

```text
VITE_NCS_API_BASE_URL=http://127.0.0.1:5000
VITE_NCS_API_KEY=<random-development-api-key>
```

浏览器中的开发 API Key 不能视为高安全密钥，它只用于学生项目联调和减少误访问。数据库安全仍依赖后端只读账号和网络隔离。

前端启动顺序：

1. 请求 `/health/ready`。
2. 请求 `/api/v1/meta/capabilities`。
3. 请求 `/api/v1/meta/filter-options?topic=stationRanking`。
4. 请求 `/api/v1/dashboard/manifest`。
5. 只加载 `available=true` 的组件。

## 7. 跨电脑局域网调试

后端电脑的 `.local/ncs.env`：

```text
NCS_QUERY_HOST=0.0.0.0
NCS_CORS_ORIGINS=http://<frontend-host>:5173
```

前端使用：

```text
VITE_NCS_API_BASE_URL=http://<backend-host>:5000
```

同时满足：

- 两台电脑网络互通；
- 后端电脑防火墙只向可信局域网开放 TCP 5000；
- 不开放 MySQL 3306、管理 API 5001 或数据库窗口 5002；
- `NCS_CORS_ORIGINS` 必须填写前端页面的完整 Origin，不使用 `*`。

调试结束后把 `NCS_QUERY_HOST` 改回 `127.0.0.1`，并关闭临时防火墙规则。

## 8. 首次建立 MySQL 结果库

仅由后端/数据库负责人执行。先在当前 PowerShell 临时设置四个连接变量：

```powershell
$env:NCS_MYSQL_MIGRATOR_URL = "mysql+pymysql://<migrator>:<password>@<vm-ip>:3306/ncs_analytics"
$env:NCS_MYSQL_PRIVILEGED_URL = "mysql+pymysql://<privileged>:<password>@<vm-ip>:3306/ncs_analytics"
$env:NCS_MYSQL_ADMIN_URL = "mysql+pymysql://<admin>:<password>@<vm-ip>:3306/ncs_analytics"
$env:NCS_MYSQL_READER_URL = "mysql+pymysql://<reader>:<password>@<vm-ip>:3306/ncs_analytics"
```

执行：

```powershell
python scripts/setup_mysql_ads.py --initialize --grant-reader --verify
```

成功结果应满足：

- `reader_physical_tables_denied=true`
- `admin_dml_only=true`
- `migrator_can_manage_schema=true`
- `reader_views` 包含 9 个视图

该脚本不创建账号、不设置密码，只初始化结构、授予固定视图权限并检查已有账号。

## 9. 导入 ADS v2.1 数据

### 命令行方式

```powershell
$env:NCS_DATABASE_URL = $env:NCS_MYSQL_ADMIN_URL
python scripts/import_ads_v21.py --package "<extracted-package-directory>" --skip-initialize
python scripts/import_ads_v21.py --package "<extracted-package-directory>" --skip-initialize --wave-b
Remove-Item Env:NCS_DATABASE_URL
```

### 管理 API 方式

启动管理服务前，`NCS_DATABASE_URL` 必须指向管理账号：

```powershell
$env:NCS_DATABASE_URL = $env:NCS_MYSQL_ADMIN_URL
python scripts/run_admin.py
```

调用：

```powershell
$body = @{
  packagePath = "<extracted-package-directory>"
  waves = @("A0", "B")
  actor = "<operator-name>"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri http://127.0.0.1:5001/internal/v1/ads-v21/imports `
  -ContentType "application/json" `
  -Body $body
```

管理 API 只应在本机使用，不开放给前端。

## 10. 完整验收

设置迁移、管理、查询三个 URL 以及 ADS 包目录：

```powershell
$env:NCS_ADS_V21_PACKAGE = "<extracted-package-directory>"
$env:NCS_MYSQL_TEST_URL = $env:NCS_MYSQL_MIGRATOR_URL
python scripts/verify_mysql_e2e.py
python -m pytest -q tests/integration/test_mysql_ads.py
```

验收包括：

- 幂等迁移；
- A0/Wave B 首次和重复导入；
- 9 个必需视图；
- 12 个非模型查询请求；
- 三账号权限边界；
- 中途失败事务回滚且无临时批次残留。

验收脚本会写入后回滚一个唯一探针批次，只能用于测试或联调数据库。

## 11. 数据库管理窗口

仅本机需要时启动：

```powershell
python scripts/run_db_console.py
```

默认地址：`http://127.0.0.1:5002/db-console`。

窗口可查看日志、执行 SQL 和检查数据库状态。它不是前端功能，不应对局域网或公网开放。执行写 SQL 前应确认连接账号和目标数据库。

## 12. 常见问题

### `NCS_DATABASE_URL is required`

确认 `.local/ncs.env` 存在、字段名正确，或者在当前 PowerShell 设置了环境变量。

### HTTP 401 `AUTH_INVALID_API_KEY`

前端没有携带 API Key，或者 Key 与后端 `NCS_QUERY_API_KEY` 不一致。

### HTTP 403 `CORS_ORIGIN_DENIED`

把浏览器开发者工具中显示的实际 Origin 加入 `NCS_CORS_ORIGINS`，包括协议和端口。

### HTTP 503 `DEPENDENCY_NOT_READY`

查询服务没有配置数据库，或连接的数据库尚未初始化。

### MySQL 1045

账号、密码或 Host 授权不匹配。检查账号是 `'user'@'localhost'` 还是远程 Host，不要通过扩大 root 网络权限解决。

### MySQL 1142

如果查询账号读取物理表时出现 1142，这是预期行为；如果读取 `api_v1_*` 视图也出现 1142，重新执行固定视图授权。

### 页面接口可访问但组件为空

检查 `/api/v1/meta/capabilities` 的 `available`，再确认 ADS 数据已经导入并发布。预测组件当前允许不可用。

## 13. 清理当前终端中的敏感变量

联调结束后执行：

```powershell
Remove-Item Env:NCS_MYSQL_MIGRATOR_URL -ErrorAction SilentlyContinue
Remove-Item Env:NCS_MYSQL_PRIVILEGED_URL -ErrorAction SilentlyContinue
Remove-Item Env:NCS_MYSQL_ADMIN_URL -ErrorAction SilentlyContinue
Remove-Item Env:NCS_MYSQL_READER_URL -ErrorAction SilentlyContinue
Remove-Item Env:NCS_MYSQL_TEST_URL -ErrorAction SilentlyContinue
Remove-Item Env:NCS_DATABASE_URL -ErrorAction SilentlyContinue
```

前端同学不应收到上述数据库变量。只向前端提供查询 API 地址和单独的开发 API Key。

## 14. 生成安全交接包

工作区干净时执行：

```powershell
python scripts/package_frontend_handoff.py
```

输出：`dist/ncs-frontend-handoff.zip`。

该压缩包只包含 Git 当前提交中的文件，不包含 `.local/ncs.env`、本地数据库、缓存或未提交文件。发送前仍应人工检查压缩包内容，并通过其他渠道单独告知临时开发 API Key。
