# 前端启动元数据接口简表

> 版本：`v1.0-rc1`
> 用途：前端启动时获取组件能力、筛选项和大屏组件清单
> 实施状态：`capabilities`、`filter-options`、`/api/v1/dashboard/manifest` 已实现并通过真实 MySQL 查询验证

以下业务值均为结构示例；各接口示例中的 `meta: {}` 表示使用第 1 节的完整公共元数据。

## 1. 通用响应

```json
{
  "code": "OK",
  "message": "ok",
  "data": {},
  "meta": {
    "requestId": "request-id",
    "dataVersion": null,
    "dataDate": null,
    "generatedAt": "2026-09-13T06:00:00+00:00",
    "staleness": "UNKNOWN",
    "empty": false,
    "partial": false
  }
}
```

## 2. 能力列表

```http
GET /api/v1/meta/capabilities
```

```json
{
  "code": "OK",
  "message": "ok",
  "data": {
    "items": [
      {
        "capabilityCode": "overview",
        "available": false,
        "registered": true,
        "endpoint": "/api/v1/dashboard/overview",
        "priority": "P0"
      },
      {
        "capabilityCode": "loadPrediction",
        "available": false,
        "registered": true,
        "endpoint": "/api/v1/predictions/load",
        "priority": "P2"
      }
    ]
  },
  "meta": {}
}
```

每项还返回正式接口路径 `endpoint` 和联调优先级 `priority`。组件代码：`globalStatus`、`overview`、`platformDistribution`、`durationDistribution`、`weekdayWeekendProfile`、`loadPrediction`、`stationHourHeatmap`、`stationRanking`、`feeEnergyTrend`、`processSummary`。

`registered=true` 表示路由已经注册，`available=true` 才表示已发布数据可用。前端只请求 `available=true` 的组件；当前 ADS v2.1/MySQL 联调库中主要非预测组件已经可用，最终状态仍以接口实时响应为准。

## 3. 筛选项

```http
GET /api/v1/meta/filter-options?topic=overview
```

`topic` 必填，使用上述组件代码。

```json
{
  "code": "OK",
  "message": "ok",
  "data": {
    "topic": "overview",
    "regions": [
      {"regionId": "region-001", "regionName": "区域名称"}
    ],
    "stations": [
      {"stationId": "station-001", "stationName": "站点名称", "regionId": "region-001"}
    ],
    "dateRange": {
      "minDate": "2019-01-01",
      "maxDate": "2019-09-13"
    }
  },
  "meta": {}
}
```

无可用筛选数据时，`regions=[]`、`stations=[]`、`dateRange=null`，同时 `meta.empty=true`。

## 4. 大屏组件清单

```http
GET /api/v1/dashboard/manifest
```

```json
{
  "code": "OK",
  "message": "ok",
  "data": {
    "items": [
      {
        "componentCode": "overview",
        "endpoint": "/api/v1/dashboard/overview",
        "priority": "P0",
        "available": false,
        "registered": true,
        "refreshIntervalSeconds": null
      }
    ]
  },
  "meta": {}
}
```

该接口返回组件代码、正式接口路径、优先级、可用状态和建议刷新间隔，不返回页面布局或 ECharts 配置。`refreshIntervalSeconds=null` 表示暂未确定自动刷新周期。

## 5. 前端调用顺序

1. 调用 `capabilities` 获取可用能力。
2. 根据页面需要调用 `filter-options`。
3. 调用 `manifest` 获取组件清单。
4. 并行请求 `available=true` 的业务组件接口。
