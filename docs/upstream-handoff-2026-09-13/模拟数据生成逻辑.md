# NCS 充电桩项目 · 模拟数据生成逻辑说明

> 归属环节：数据模拟（本负责人分工）
> 配套文件：`02_gen_aug_sim_data.py`（生成器 v2）+ `real_dist.json`（真实分布模型）
> 更新日期：2026-09-13

---

## 1. 为什么需要模拟数据

真实数据（老师发放：3,395 订单 / 1,594 监测 / 105 站点）用于正式分析；模拟数据用于：

1. **链路测试**：数据未到位时验证 ODS→DWD→DWS/ADS 全链路
2. **容量验证**：生成更大规模数据测试 Hive 处理能力与大屏性能
3. **分布验证**：以"模拟分布≈真实分布"证明生成方法的有效性

## 2. 核心思路：从"贴格式随机"升级为"分布一致生成"

| 版本 | 思路 | 问题 |
|---|---|---|
| v1（gen_sim_data.py） | 按字段格式随机生成（均匀/正态假设） | 分布与真实偏差大：周末订单不会少、监测每会话多条、费用/电流分布不符 |
| **v2（当前）** | **先统计真实数据分布 → 按分布采样生成** | 分布规律与真实一致或相似 ✅ |

v2 分两步：
```
真实 CSV ──(统计)──> real_dist.json（分布模型）──(采样)──> 模拟 CSV
```

## 3. 分布学习（real_dist.json 的内容）

对真实数据逐字段统计得到分布模型，关键分布如下：

| 分布 | 真实数据特征（学到的） |
|---|---|
| 小时分布 | 双高峰：11点(504)、12点(475)、17点(437)、16点(404)；夜间极少 |
| 星期分布 | 工作日多（Mon~Fri 各 610~735）、周末极少（Sat 62 / Sun 24） |
| 月份分布 | 1~9 月逐月递增（39→760）、10 月起骤降（95→14） |
| 年份异常 | 0014 占 0.7%、0015 占 99.3%（源数据截断写法） |
| 平台占比 | ios 65.8% / android 34% / web 0.2% |
| 设施类型 | 3型 54% / 2型 25% / 1型 17% / 4型 3% |
| 站点热度 | 105 站幂律长尾（TOP1 站点 334 单） |
| kwh 分位 | P25=4.35 / P50=6.23 / P75=6.83 / P100=23.68 |
| 时长分位 | P25=2.11h / P50=2.81h / P75=3.54h（含 55h 极端长时） |
| 隐含功率 | 电量/时长，P50=2.11kW，长尾至 45.96kW |
| 费用 | 88.84% 为 0；非0费用 70% 为 0.5 元（P10~P70 均为 0.5） |

| 电压/SOC | 按真实分位（P25/P50/P75）采样 |
| 监测结构 | **每会话 1 条采样**；会话占比 1594/3395≈47% |

## 4. 生成算法（订单逐字段）

```
对每个订单（共 N 个）：
1. weekday    ← 按真实星期分布加权采样（工作日多、周末少）
2. 月份       ← 按真实月份分布加权采样（1~9月多）
3. 年份       ← 按真实年份分布采样（99.3% 取 0015）
4. 日期       ← 日 1~28 均匀，小时按真实小时分布采样，分秒均匀
   → created = "00{yr}-{mm}-{dd} HH:MM:SS"（与真实异常年份格式一致）
5. 时长       ← 按真实时长分位数线性插值采样（q_sample）
6. 隐含功率   ← 按真实功率分位数采样
7. 电量 kwh   ← 时长 × 功率（保持字段相关性！），截断到真实 kwh 上限
8. 费用       ← 88.84% 概率为 0；否则 = kwh × 单价(真实分位采样)，截断到非0费用上限
9. 结束时间   ← created + 时长（取整小时），endTime 列 = (开始小时+时长取整)%24
10. 平台      ← 按真实平台分布加权采样
11. 站点      ← 按真实 105 站热度加权采样；locationId 从真实站点表映射
12. 设施类型  ← 按真实分布采样
13. managerVehicle ← 5% 概率为 1
14. sessionId/userId ← 数字风格（与真实一致）
15. 星期列 Mon..Sun ← 按采样的 weekday 置 1，其余 0
```

**关键设计——分位数插值采样（q_sample）**：把真实数据从小到大排序，取 0/5/10/…/100 百分位值存入模型；生成时随机取一个百分位 p，在相邻两个分位点之间线性插值得到数值。优点：**完整保留真实分布的形状**（含长尾），而不是假设正态/均匀。

**关键设计——字段相关性**：真实数据中 kwh、时长、费用是关联的（电量≈时长×功率，费用≈电量×单价）。v2 通过"先采样时长 → 采样功率 → 计算 kwh → 采样单价 → 计算费用"的**链式生成**保持相关性，避免"各自独立随机"导致的失真。

## 5. 生成算法（监测数据 + 站点）

**监测数据（dsv13r2.csv）**：
```
对每个订单：47% 概率生成 1 条监测记录（真实：每会话 1 条采样）
  esd          = 订单 sessionId（100% 关联，与真实一致）
  record_time  = 科学计数法毫秒时间戳（如 1.55E+12，DWD 层靠 esd 关联修复时间）
  soc / 电压 / 电流 / 温度 ← 按真实分位采样
  电流集中 -22.5A（真实特征：负值放电）；温度 32~37℃
  available_energy/capacity ← 与订单电量相关 + 合理范围
```

**站点表（nvv2t_md_end.csv）**：直接使用真实 105 站元数据原样输出——站点 ID、区域、设施类型、名称、地址、设备数、运营时间、更新时间**与真实完全一致**，保证订单-站点关联可 JOIN。

## 6. 数据增强模式（--augment）

对**真实数据本身**做变换生成新样本（常见数据增强方法）：

| 增强手段 | 实现 |
|---|---|
| 时间偏移 | created/ended 整体偏移 N 天（--offset-days） |
| 数值扰动 | kwh/费用/电流乘以 (1±noise) 随机扰动（--noise） |
| 站点重组 | 真实站点 ID 随机打乱映射（订单/监测/站点三表同步重映射，保持关联） |

```
python 02_gen_aug_sim_data.py --augment --real-dir 真实CSV目录 --offset-days 90 --noise 0.05 --out 输出目录
```

## 7. 用法

```cmd
:: 模式1：分布采样生成（默认，推荐）
python 02_gen_aug_sim_data.py --orders 5000 --out 输出目录 --seed 42

:: 模式2：数据增强
python 02_gen_aug_sim_data.py --augment --real-dir 真实CSV目录 --offset-days 90 --noise 0.05 --out 输出目录
```

| 参数 | 含义 |
|---|---|
| --orders | 生成的订单数量（默认 5000） |
| --seed | 随机种子（可复现） |
| --dist | real_dist.json 路径（默认脚本同目录） |
| --augment / --real-dir / --offset-days / --noise | 增强模式参数 |

输出：`nvv2t.csv`（订单）/ `dsv13r2.csv`（监测）/ `nvv2t_md_end.csv`（站点），表头与真实完全一致（UTF-8 BOM）。

## 9. 用途与注意事项

- **正式分析**用真实数据（`ncs_*` 库）；**测试/大屏演示**用模拟数据（`ncs_sim_*` 库，平行库隔离）
- 模拟数据分布与真实一致，但不代表真实业务含义（如 0014/0015 年份为源数据特征，模拟沿用以便 DWD 清洗逻辑可复用）
- 预生成好的 5000 订单模拟数据在交付包 `simdata/` 目录，已在本机分布验证 + node100 全链路验证通过
